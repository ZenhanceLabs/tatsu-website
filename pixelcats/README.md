# 🐱 Cat Animation Engine Handoff (App Development Team)

このフォルダには、React Native（またはその他のフロントエンド）アプリで「動くドット絵の猫」を実装するためのデータと、アニメーションロジックのレファレンスが含まれています。

## 📁 含まれるファイル
- `catPatterns_*.ts` : アプリ側にそのままimportして使用できるTypeScriptの固定データ群です。各ファイルには数十匹の猫データが配列として格納されています。

---

## 🎨 猫データの構造（CatPattern型）
各猫は以下のインターフェースを持っています。

```typescript
interface CatPattern {
  id: string;               // 一意のID (例: "C001", "sakura")
  name: string;             // 英語名 (例: "Classic White")
  name_ja: string;          // 日本語名 (例: "しろねこ")
  description_ja: string;   // 猫の説明文
  rarity: number;           // レア度（1〜4など）
  status: string;           // "approved"
  
  // -- カラーフォールバック定義 --
  faceC: string;            // 顔（ベースの毛色）のパレットキー (通常 "1")
  eyeC: string;             // 目のパレットキー (通常 "2"、光る猫は "6"や"7"など)
  outlineC: string;         // 輪郭線のパレットキー (通常 "2"、光る猫は特殊)
  earInC: string;           // 耳の中のパレットキー (通常 "3")
  pawC: string;             // 肉球・前足のパレットキー (通常は顔色と同じ)
  
  // -- カラーパレット --
  pal: Record<string, string>; // キー(1〜9等)と16進数カラーコードの対応表
  
  // -- ピクセルデータ --
  data: string[];           // 21行の文字列。1文字が1ピクセル（横21×縦21）を表す
  
  // -- 拡張レイヤー（一部の猫のみ） --
  faceOverlay?: string[];   // 目や顔のパーツの手前に絶対固定される21x21のレイヤー
}
```

## 🏃 アニメーションロジックの仕様書
アニメーションは「21x21」の二次元配列（`frame`）を毎フレーム書き換えて描画することで実現します。

### 1. 毎フレームの描画パイプライン
1. **キャンバスの初期化**: 毎回キャンバスをクリアします。
2. **データのコピー**: `cat.data` (元の21x21配列) を `frame` 変数にディープコピーします。
3. **状態管理（State）**: 現在の時刻（または一定のサイクル）に基づいて、猫のアクション状態（`head`, `eyes`, `mouth`, `action`, `tail`, `ear`, `particles`）を判定します。
4. **部位ごとの書き換え（上書き）**: 判定したアクションに合わせて、特定のピクセル座標を別な色（パレットキー）で上書きします。
5. **レンダリング**: 最終的な `frame` 配列を `x`, `y` のループで回し、`cat.pal[キャラ]` の色で `fillRect` します。

---

### 2. 重要：アニメーション時の「色のサンプリング（色抽出）」
単純に特定の色コードでアニメーション部分を上書きすると、猫の模様（三毛猫やブチなど）と合わずに**「黒い背景に変な色が乗る」「縞模様が途切れる」**といったバグが発生します。必ず以下の場所から動的に色を取得（サンプリング）してアニメに利用してください。

#### ① 顔（頭）を動かす時の背景と、まばたきに使う色
顔を動かす際、元の顔があった場所を「毛色」で塗りつぶす（消す）必要があります。
必ず**顔付近の毛の色を同じ行からサンプリング**してください。
```javascript
// まばたきや顔移動時に使う「ニュートラルな毛色」
let fur6 = cat.data[6][8] !== '0' ? cat.data[6][8] : cat.faceC;
let fur7 = cat.data[7][8] !== '0' ? cat.data[7][8] : cat.faceC;
```

#### ② 顔かき（Scratch）時の前足の色
前足のアニメーションを行う際、前足の「枠線の色」と「中身の色」が猫によって異なります。
**前足の枠線は必ず「一番下の中央のピクセル」からサンプリング**してください。（これが必ずその猫の正確なベース輪郭線になります）
```javascript
// 枠線は Row 20, Col 8 から取得
let dynPawOut = cat.data[20][8]; 
// 中身の毛色は Row 14, Col 8 (胸〜お腹付近) から取得
let dynPawFill = Array.from(cat.data[14])[8] !== '0' ? cat.data[14][8] : cat.faceC;
```

顔かきのために元の前足があった場所（Row 16〜19, Col 5〜7）を消す時は、同じ行の Col 8 の色（胸の色）を使って塗りつぶします。

#### ③ あくび時の口と舌
```javascript
let mouthLine = cat.data[8][8] !== '0' ? cat.data[8][8] : cat.outlineC;
// 舌の色は通常ピンクである【耳の中の色(earInC)】を使います
// frame[9 + dy][8 + dx] = cat.earInC; 
```

---

### 3. faceOverlay（顔レイヤー）の扱い
`cat.faceOverlay` が定義されている場合（歌舞伎猫の隈取、忍者の覆面、サイバーキャットなど）、顔の描画後にこのレイヤーを上書きします。
重要な点として、**Row 6〜10, Col 5〜15 の範囲にある overlay のピクセルは、顔の移動（`dx`, `dy`）に合わせて一緒にずらす（+dx, +dy）**必要があります。これにより、顔の模様や装飾が顔と一緒に動きます。

実装に迷った場合は、Web側のプロトタイプである `pipeline/index.html` の `drawCat()` 関数が「正の仕様（リファレンス実装）」となりますので、そちらのコードのピクセル座標指定をそのままTypeScript/React NativeのCanvas（またはピクセルレンダラ）に移植してください。
