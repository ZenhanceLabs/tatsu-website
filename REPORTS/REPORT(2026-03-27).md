# REPORT (2026-03-27) — TATSU 多言語対応 (EN/KO)

## 変更点

### ウェブサイト
- `index.html`: JS ベースの i18n エンジン導入（50+ 翻訳キー、JA/EN/KO）
  - ブラウザ言語自動判定 + localStorage 保存
  - 🌐 言語セレクター（ナビバー）
  - カルーセルのスクリーンショット切替（`screenshot/*_en.png`, `*_ko.png`）
  - フォント: JA=Noto Sans JP / EN=Noto Sans / KO=Noto Sans KR
  - OGP/title/lang 動的更新
- `contact.html`: 同様の i18n 対応

### Play Store 画像
- `generate_slides.py`: `--lang en|ko` 引数追加、フォント・テキスト・SS 切替
- `generate_feature_graphic.py`: `--lang en|ko` 引数追加
- `description_en.txt` / `description_ko.txt`: 新規作成（ストア説明文）
- EN/KO 各 8 枚のスライド + フィーチャーグラフィック生成済み

### 広告動画 (Remotion)
- `i18n.ts`: 翻訳辞書（曜日ラベル、UI テキスト、CTA）
- `TatsuPromo.tsx`: `lang` prop で全テキスト翻訳対応
- `Root.tsx`: `TatsuPromoEN`/`TatsuPromoKO` Composition 追加
- `package.json`: `render:en`/`render:ko` スクリプト追加

## 影響
- 既存の日本語版には影響なし（`--lang ja` がデフォルト）
- 新しいファイル追加のみ、既存ファイルの構造変更は最小限
